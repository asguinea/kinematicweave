# Security policy

## Supported versions

KinematicWeave is pre-1.0 research software. Security fixes are applied to the
current default branch; older snapshots are not maintained.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a suspected vulnerability and do not include
credentials, private datasets, or identifying records in a report.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. You should receive an acknowledgement within seven days.
If private vulnerability reporting is not enabled, contact the repository
owner privately through their GitHub profile.

## Scope

Reports about path containment, archive extraction, untrusted structured data,
artifact integrity, command execution, and dataset acquisition are especially
useful. Scientific disagreements and ordinary incorrect outputs should use the
regular issue tracker unless they also create a security or privacy risk.
